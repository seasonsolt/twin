# 分身可以了解你的哪些方面（v1）

记忆可以随时自由添加，不必先填问卷，也不必按顺序补齐。网页“关于你”展示分身了解到的内容，
你可以确认、修改或否定。每条内容都保留可核对的原文、日期和来源。

## 从哪里了解

- 笔记、文章、聊天记录：本人写下或实际说过、做过的事。
- 可选问卷、访谈：本人对自己的描述。
- 内容不一致时，优先参考本人实际做过的事，保留差别供本人核对，不替本人下定论。
- 不记录对具体他人的评价或他人隐私。原文保存在本地；进入抽取、检索和回答时按配置替换已知的他人姓名。
  旧来源缺少 `text_state` 时不重复化名，遗失的真名不能恢复。

## 回答几个问题（可选）

`persona/questionnaire.py` 提供 20 题，覆盖九个方面，全部可跳过。题目用日常语言，
回答自动保存，可以分几次填写；提交后所有回答都成为记忆，没有测试题或第二轮。
提交会替换此前的在线问卷来源，不影响自由添加的记忆。

生活与喜好仍只在本人回答相关问卷、且没有跳过拒绝相应内容时允许提炼；跨问卷拒绝优先。
其他问题跳过不会禁止从自由添加的记忆了解相关内容。旧版本答案不会显示在新题目下面，
已导入的旧问卷记忆保留，下一次提交可替换它。

## 看看还可以分享什么

网页只显示已经了解到的内容和少量主题建议。CLI `twin persona coverage` 保留较详细的报告：
“已了解一些 / 了解较多 / 回答经过检查”、内容来源，以及可以再分享什么。

内部计算仍参考不同来源和日期的例子数（同一来源同一天算一次），是否有实际做过的事，
以及是否有两类来源。最近在关注只参考最近 90 天；内容有冲突时降低把握。
这些数字是帮助发现缺口的线索，不是对人的打分，也不要求用户达到某个比例。
独立评测见 [PERSONAL_EVAL.md](PERSONAL_EVAL.md)，不使用这里的问卷答案当作留出测试。
