# 问卷评测

用一份固定的选择题问卷，测分身"像不像你"。做法借鉴 Park 等人的论文（arXiv:2411.10109，
*LLM Agents Grounded in Self-Reports Enable General-Purpose Simulation of Individuals*）：
**你自己的答案是标准答案**；隔一段时间你再答一次，两次答案的一致率是天花板；
分身准确率除以这个天花板，就是**归一化准确率**。

和论文不同的地方：

- **分身可以说不知道。** 默认允许弃权，所以分开报告"作答率"、"只算作答题的准确率"和
  "弃权算错的准确率"。加 `--force-choice` 要求必选，和论文的做法一致，便于对比。
- **不看答案先作答。** 阅卷时先选你自己的答案，再显示分身选了什么、怎么说的，
  避免先看到分身的答案而被带偏。
- **给理由打分。** 看完分身的话，可以给"理由像不像你"打 1–5 分，这一项论文里没有。

## 用法

```sh
# 1. 分身答卷（每题 3 次取多数；答卷含你的个人信息，放在仓库外）
twin survey ask --out ~/twin-private/survey-1.json

# 2. 你来阅卷：先选自己的答案，再看分身的；随时 q 退出，下次接着阅
twin survey grade ~/twin-private/survey-1.json

# 3. 隔两周左右，你自己再答一次（不调用分身）
twin survey self --out ~/twin-private/survey-retest.json

# 4. 统计（不调用模型）
twin survey score ~/twin-private/survey-1.json --retest ~/twin-private/survey-retest.json
```

其他选项：`--repeats` 每题作答次数；`--as-of YYYY-MM-DD` 让分身只用那天以前的资料；
`--instrument` 换成自己的问卷 JSON（格式同 `src/twin/evals/instruments/survey_zh_v1.json`）。

## 报告里的数字

| 指标 | 含义 |
| --- | --- |
| 准确率（弃权算错） | 分身的选择和你一样的题数 ÷ 你答了的题数；带按题 bootstrap 的 95% 区间 |
| 准确率（只算作答的题） | 分身没说不知道的题里，选对的比例 |
| 作答率 | 分身给出选择的比例 |
| 随机猜的准确率 | 每题 1/选项数的平均，用来判断分身是不是比瞎猜强 |
| 量表题平均偏差 | 五级量表题差了几档，换算到 0–1 |
| 理由像不像你 | 你给分身理由打的分（1–5） |
| 分身多次作答一致率 | 同一题几次作答选同一个答案的比例，衡量分身自己稳不稳 |
| 你两次作答的一致率 | 天花板：你自己隔一段时间能复现自己多少 |
| 归一化准确率 | 同一批题上，分身准确率 ÷ 你的一致率；区间按题配对 bootstrap |

## 注意

- **答卷不要导入成记忆。** 否则之后的分身等于提前看了标准答案。
- **一个人、48 道题，区间会很宽。** 结论要靠多位志愿者；单人结果只看方向。
- 问卷题目和分身已有的引导问卷（`persona/questionnaire.py`）不重复；
  如果你的资料里有和问卷几乎一样的问答，那几道题的结果偏乐观。
- 问卷只测"你说自己会怎么做"（自述）。"你实际怎么做"要用时间留出的行为评测，另行设计。

## 内置问卷（zh-v1，48 题）

面向普通人：不需要特定职业背景，避开政治和宗教，大约 10 分钟答完。8 个方面各 6 题，
其中经济决策类题目（d1、d2、s3、s4）改编自风险偏好、时间偏好、独裁者博弈和信任博弈的常见设计，
措辞为原创，其余题目也都是原创。每题标了对应的人格细项（`facet`），方便和档案对照。
