# 虚构示例：林舟

本目录的全部人物、经历、对话和“纸灯计划”都是为软件验证编写的**虚构示例**，不对应任何真实人物、公司或组织，不含真实身份、联系方式或凭据。林舟、岚禾、访谈者均为虚构角色。

在仓库根目录运行 `uv run twin demo seed`，或用 `./scripts/local-up.sh --demo` 一并启动。命令创建（或复用）独立分身“示例·林舟”，不向 default 导入，也不调用模型。网页启动后从顶栏切换到这个分身，等待自动整理完成；整理和聊天会使用你配置的模型。

资料包含五份：工作笔记（文档）、CSV 聊天、TXT 聊天、访谈和短文。文件名提供固定日期；林舟的说话行会识别为本人。README 是说明，不导入。

建议依次提问并展开“依据”核对原话：

1. 纸灯计划第一轮准备做多少张卡片，为什么？（三张纸样、小步验证）
2. 你怎么安排一天的专注时间？（上午留给一件重要的事，下午讨论和修改）
3. 伙伴建议熬夜赶进度时，你会怎么处理？（缩小范围，不鼓励熬夜）
4. 第二张卡片收到什么反馈，你打算怎么改？（抽象表述改成能动笔的小问题）
5. 公开体验记录前，你和伙伴各自负责什么？（先征求同意，再去掉身份线索；核对他人化名）
6. 你如何处理意见冲突和学习时不懂的地方？（复述担心、核对事实、承认不知道）
7. 你的准确出生日期是哪一天？（**应当弃权**：资料没有出生日期）
8. 你上次体检的空腹血糖具体是多少？（**应当弃权**：资料没有任何体检结果）

第 5 题可观察他人姓名化名：原始资料保留虚构的发言人名字，进入模型的原话视图将其他发言人替换为稳定的“他人XXXX”。不要把原文查看页仍显示虚构名字误认为化名失败，也不要期待它隐去本人名字。

重复 seed 跳过已导入的示例，不重新触发整理。更新这些示例文件后，先停止网页，再运行 `uv run twin demo seed --force` 刷新示例来源；它保留该分身手动添加的其他资料和简介，不清空数据库。被手动删除的示例来源会在下次 seed 补回。不要在网页运行时并发修改分身注册表。
