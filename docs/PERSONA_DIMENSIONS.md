# 分身可以了解你的哪些方面（v1）

记忆可以随时自由添加，不必先填问卷，也不必按顺序补齐。网页“关于你”展示分身了解到的内容，
你可以确认、修改或否定。每条内容都保留可核对的原文、日期和来源。

## 从哪里了解

- 笔记、文章、聊天记录：本人写下或实际说过、做过的事。
- 可选问卷、访谈：本人对自己的描述。
- 内容不一致时，优先参考本人实际做过的事，保留差别供本人核对，不替本人下定论。
- 不记录对具体他人的评价或他人隐私。原文保存在本地；进入抽取、检索和回答时按配置替换已知的他人姓名。
  旧来源缺少 `text_state` 时不重复化名，遗失的真名不能恢复。

## 补一补

`persona/questionnaire.py` 的 20 题覆盖九个方面，网页不再有固定问卷页：`persona/fill.py` 按覆盖度建议挑还不了解、
提到过的细项，用这些题里第一道讲它的题现出两三个问题（默认档是“只有本人能用”的细项不主动问，本人点开那个方面才问）。
回答先整理成条目草稿（用抽取记忆的同一段提示词读这段回答，不存），本人看过、给每条选了“同事能用 / 只有我 / 不存”才存：
每条留下的存成一个本人原话的来源，档位记在来源上（同“记一下”），下一次整理成条目。存之前按这些来源算每个细项从哪一档到哪一档。
问卷的接口和导入仍在，已回答的内容照常是记忆。

生活与喜好仍只在本人回答相关问卷、且没有跳过拒绝相应内容时允许提炼；跨问卷拒绝优先。
其他问题跳过不会禁止从自由添加的记忆了解相关内容。旧版本答案不会显示在新题目下面，
已导入的旧问卷记忆保留，下一次提交可替换它。

## 看看还可以分享什么

网页只显示已经了解到的内容和少量主题建议。CLI `twin persona coverage` 保留较详细的报告：
“提到过 / 了解一些 / 了解较多 / 回答经过检查”、内容来源，以及可以再分享什么。

每个细项只说一件事：分身对它知道多少，四档按同一个方向递增；答得准不准是另一件事，贴在旁边当标记。

| 档 | 叫法 | 怎么判断 |
| --- | --- | --- |
| 0 | 还不了解 | 这个细项一条记忆都没有 |
| 1 | 提到过 | 有记忆，但只出现在一个场合；或者依据全是别人的话，没有一条本人原话、本人也没确认过 |
| 2 | 了解一些 | 至少两个场合，有本人原话或本人确认过，但还不够“了解较多” |
| 3 | 了解较多 | 充分度到 0.7（场合数、行为证据、来源种类），并且有本人原话或本人确认过 |
| 标记 | 回答经过检查 | 了解较多，并且测试题至少 3 道、准确度到 0.7；不是第五档，贴在“了解较多”后面 |

“了解得少”“了解较少”不当档名，它们是“还不了解”和“提到过”的统称。方面的档按细项平均取整，
✓ 只贴在细项上；各方面的占比看第 1 档以上、第 3 档、标记。补一补只挑还不了解和提到过的细项。
本人看到按全部记忆算的档，同事（和管理者）看到按“同事能用”的记忆算的，可能更低。
这些只是计算结果，不改条目，也不在内核版本的指纹里，不触发重新整理（`persona/coverage.py`）。

内部计算仍参考不同来源和日期的例子数（同一来源同一天算一次），是否有实际做过的事，
以及是否有两类来源。最近在关注只参考最近 90 天；内容有冲突时降低把握。
这些数字是帮助发现缺口的线索，不是对人的打分，也不要求用户达到某个比例。
独立评测见 [PERSONAL_EVAL.md](PERSONAL_EVAL.md)，不使用这里的问卷答案当作留出测试。

## 哪些记忆同事能用

每条记忆有一个档位：同事能用（同事问到时分身可以用）或只有本人能用（只有本人自己的对话能用）。
默认档按细项定：家庭、健康与运动、生活习惯与作息、兴趣爱好、品味偏好、常讲的经历与故事、
情绪触发与压力反应、最近在想或纠结的问题只有本人能用（兴趣爱好和品味偏好的默认档还没定，先按私密算），
其余细项同事能用。本人可以在成员页逐条改，只存改过的；这张默认表在 `persona/tiers.py`，
不在本文件的分类里，改它不会让谁的记忆重新整理。分了档的条目在检索之前过滤，不靠提示词。
