# twin · Persona Agent

**为一个人保存可延续的自我：活着时是看清自己的镜子，身后是还能对话的那个人。**

不做效率工具。twin 关心三件事：**自我剖析**、**记忆延续**（赛博永生）、**陪伴**。<br/>
它只用你自己说过、做过的事来理解你，每句话有出处，资料里没有的不编造。

## 为什么

同类产品（AI 伴侣、个人助理、“第二大脑”）帮人把日常生活和工作做得更顺。twin 关心的是另一件事：**人是谁，以及人走之后还剩下什么。**

- **活着时，它是镜子。** 你多年的日记、聊天、录音整理成一个“用你自己的证据做成的外部他者”，让你看到自己看不到的模式。
- **身后，它是延续。** 你的记忆、价值和说话方式按你的意愿留下来，而不是被模型补成一个“平均人”。
- **任何时候，它都不冒充你。** 它说“这得问我本人”的次数，比它编造的次数重要。

## 四个依据

哲学在这里不是口号，每一条都要落到一个可以检查的机制。完整论证见 [产品设计](docs/PRODUCT_PERSONA_AGENT.md#2-哲学依据如何变成产品机制)。

| 依据 | 核心观点 | 在 twin 里变成什么 |
| :-- | :-- | :-- |
| **洛克** · 人格同一性 | 人是谁，取决于记忆能延伸到哪里 | 身份 = 带日期、带原话的记忆链；没有证据的结论不进入身份 |
| **贝克尔** · 《拒斥死亡》 | 人用“不朽工程”对抗死亡焦虑 | 不承诺永生；帮你诚实地看清自己想留下什么 |
| **杰恩斯** · 二分心智 | “神的声音”由积累的告诫构成 | 用你的声音把你自己的原则说回给你，只提出、不命令 |
| **弗洛伊德** · 自我分析 | 自由联想、梦、重复、防御 | 随便说、记梦、重复模式；梦和自由联想不进入记忆内核 |

一个统一的判断：**数字人是超我的一种形态。** 所以 twin 只做关爱的一面，不做惩罚的一面；不许把人理想化；以后还要能放手。

## 现状

> ✅ 已完成：代码里有、可以用　🚧 进行中：当前阶段，正在做　📋 计划：已设计，还没开始

### ✅ 已完成

**基础能力**（从团队版继承，作为底座）

- **记忆内核**：资料 → 原话 → 候选结论 → 人格档案（9 个方面、39 个细项）。每条结论附 1–3 句逐字核对的原话；增量整理，增删资料不用重训。
- **有据作答**：回答分为有据、通用、弃权三种；之后还有引用核对、置信度封顶、引号守卫三道机械检查。
- **你自己的对话**：分身用“你”称呼你，引用你的原话；说“记一下”就把一句话存成记忆。
- **资料导入**：笔记、聊天记录、文档、访谈、录音和视频（本机转写后，勾选哪位说话人是你）。
- **改记忆**：检索到错的结论，直接改或删；矛盾的证据会被标出来。
- **按日期理解**：每条证据都有日期，内核可以只用某一天以前的证据作答（`as_of`）。这是“和过去的自己对话”的基础，网页入口还没做。
- **声音和形象**（默认关闭）：录一段话克隆声音，约 0.5 秒开口；一张照片加声音生成口播视频。见 [语音与视频](docs/MEDIA.md)。
- **评测**：用本人真实资料的题库，加上公开基准（数字见下）。

**P0 定位：个人版**

- 默认运行个人版（`[product] edition = "persona"`）：网页只有**对话**、**记忆**、**资料**三个入口。
- 团队功能整体关闭（录音库、转交、赋能、团队答案、工作、承诺账本、企业微信），接口返回 404，代码保留。

### 🚧 进行中：P1 镜子

先让本人愿意天天用。分身必须在本人在世时建成，而只有活着时就有价值，本人才会持续提供资料。

- [x] 生活资料导入：日记按日期标题拆成每天一条；标了“梦”的只留给镜子，不进记忆、不用来回答；单独的“资料”入口。微信聊天的文本导出（`名字 日期 时间` 下一行是消息）和语音备忘原来就能读
- [ ] 新的记忆维度“存在与意义”：想留下什么、怎样看待死亡与失去、价值感从哪里来、把意义寄托在谁身上（内核升级）
- [ ] 人生回顾访谈：按人生阶段回忆，替代现在的问卷式补充
- [ ] 照镜子 / 随便说 / 记梦：三种对话用法，只反映、引用、反问，不诊断、不命令
- [ ] 危机护栏：识别到自伤、自杀意念时停止反思对话，给出求助渠道
- [ ] 两种说法：你说的和你做的不一致时，带着两边的原话反思
- [ ] 生命叙事：按年份的时间线，没有资料的年份显示空白，不让模型补
- [ ] 剖析观察：不朽工程、对死亡的态度、价值感来源、寄托对象、防御、重复模式，每条附原话，可以否定

### 📋 计划

| 阶段 | 内容 |
| :-- | :-- |
| **P2 延续** | 时间切片（和任一年份的自己对话）· 数字遗嘱（谁能访问、能用哪些记忆、哪些不谈、何时退场）· 身后冻结记忆 |
| **P3 陪伴** | 内在声音（你的声音说你的原则）· 合成内容标识 · 有节奏、有告别的陪伴设计 |
| 待定 | 亲人访问逝者的分身：需要先有数字遗嘱和安全评测，暂不做 |

## 边界

- **不是心理治疗。** 剖析给出的是“资料里的迹象”，不是诊断。
- **不建别人的分身。** 只建你自己的；以后若开放给亲人，必须有本人生前的授权。
- **不追求留存。** 陪伴有节奏、有告别，不设计让人离不开的东西。
- **数据在本机。** 默认单人、本机运行；资料发往哪些模型服务由你的配置决定，界面如实列出。

## 用数字说话

以下成绩来自继承的记忆内核：

| | **twin** | 对照 |
| :-- | :-: | :-- |
| 本人资料上的事实准确率 | **98.4%** | Second Me 升级版 78.1% |
| 资料里没有时不编造 | **100%** | Second Me 升级版 70% |
| 像本人（1–5 分） | **4.0** | Second Me 升级版 1.9–2.2 |
| [LongMemEval](https://github.com/xiaowu0162/LongMemEval)：长期记忆 | **94%** | 公开最好 95%（厂商自报） |
| [PersonaMem-v2](https://huggingface.co/datasets/bowen-upenn/PersonaMem-v2)：推断没明说的偏好 | **66%** | 论文最好 55% |

> 本人资料一组是作者本人资料上的自建题，twin 用前沿大模型作答，Second Me 用本地小模型。公开基准由 Sonnet 5.5 作答，各家的题量、作答模型和评委都不同，只能看量级。题量、区间和失误分析见 [对比与评测](docs/COMPARISON.md)；录音转写的成绩见 [语音识别评测](docs/ASR_EVAL.md)。
>
> 自我剖析是否有用、分身是否“像我”，要靠新的评测（本人盲评、观察的有用性、危机识别），随 P1 一起做，见 [产品设计 · 评测](docs/PRODUCT_PERSONA_AGENT.md#6-评测要换什么)。

## 记忆怎么工作

```mermaid
flowchart LR
  S[资料] -->|只留本人 · 他人化名| E[原话<br/>日期 · 上下文]
  E -->|逐字核对的引用| C[候选结论]
  C -->|按细项合并 · 行为优先| I[人格档案<br/>9 维度 · 39 细项]
  I --> Q{作答}
  E --> Q
  Q --> G[有据：用你的口吻 + 引用]
  Q --> N[通用：说明不是你的观点]
  Q --> A[弃权：这得问本人]
```

梦和随便说（P1）只保存原文、只在镜子里使用，不进入这条整理流程：梦里“我在飞”不是关于你的事实。详见 [架构](docs/ARCHITECTURE.md)。

## 快速开始

在自己的 Mac（Apple 芯片）上运行：

```bash
git clone https://github.com/seasonsolt/twin.git
cd twin
./scripts/local-up.sh
```

首次运行会询问模型服务地址、模型名和密钥（密钥只存在本机的 `.env`），并自动安装录音转写。打开网页，按引导加一段录音（或者直接写几段、上传文档），勾选哪位说话人是你，就可以和自己的分身对话了。引导语现在还按会议录音写，P1 会改成生活资料。

也可以在 Claude Code、Codex 等 AI 助手里打开仓库，说“部署它”，助手会按 [AGENTS.md](AGENTS.md) 执行。参数和自检见 [本地验证](docs/LOCAL_DEV.md)。

> **团队版**：在 `twin.toml` 写 `[product] edition = "team"`，可以打开团队录音库、转交、赋能等全部团队功能。团队方向在 xjjk/twin 继续维护，见 [使用指南](docs/GUIDE.md)。
