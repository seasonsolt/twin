# 问卷评测

用一份固定的选择题问卷，测分身"像不像你"。做法借鉴 Park 等人的论文（arXiv:2411.10109，
*LLM Agents Grounded in Self-Reports Enable General-Purpose Simulation of Individuals*）：
**你自己的答案是标准答案**；隔一段时间你再答一次，两次答案的一致率是天花板；
分身准确率除以这个天花板，就是**归一化准确率**。

和论文不同的地方：

- **分身可以说不知道。** 默认允许弃权，所以分开报告"作答率"、"只算作答题的准确率"和
  "弃权算错的准确率"。加 `--force-choice` 要求必选，和论文的做法一致，便于对比。
- **不看答案先作答。** 阅卷时先选你自己的答案，再显示分身选了什么、怎么说的，
  避免先看到分身的答案而被带偏。
- **给理由打分。** 看完分身的话，可以给"理由像不像你"打 1–5 分，这一项论文里没有。

和论文一样的地方（v2 起）：

- **人格用多题量表计分。** 论文用 BFI-44；我们用公共领域的 **Mini-IPIP**（20 题，每个特质 4 题），
  算出五个特质分数，报告偏差和相关；有重测时报告归一化相关（分身相关 ÷ 你两次的相关）。
- **防泄漏。** 论文去掉了和访谈问题重复的 27 道 GSS 题。我们在作答前把每道题和记忆里"你被问过的问题"
  比对：字面相似的候选交给模型判断是不是同一个问题；题目原文直接出现在记忆里的也标出来。
  这些题照常作答，但**默认不计分**。
- **基线。** 论文的"自述段落"基线对应 `--baseline intro`（只看你在档案里写的自我介绍）；
  另有 `--baseline blank`（没有任何信息），衡量模型只靠常识能猜对多少。基线不用再阅卷，用已阅的分身答卷当标准答案。

## 用法

```sh
# 1. 分身答卷（每题 3 次取多数；先做防泄漏检查；答卷含个人信息，放在仓库外）
twin survey ask --out ~/twin-private/survey-1.json

# 2. 你来阅卷：先选自己的答案，再看分身的；随时 q 退出，下次接着阅
twin survey grade ~/twin-private/survey-1.json

# 3. 隔两周左右，你自己再答一次（不调用分身）
twin survey self --out ~/twin-private/survey-retest.json

# 4. 统计（不调用模型）
twin survey score ~/twin-private/survey-1.json --retest ~/twin-private/survey-retest.json

# 5. 基线：同一套题，只看自我介绍 / 什么都不看，用第 2 步的答卷计分
twin survey ask --baseline intro --out ~/twin-private/survey-intro.json
twin survey score ~/twin-private/survey-intro.json --key ~/twin-private/survey-1.json
```

其他选项：`ask` 的 `--repeats` 每题作答次数，`--as-of YYYY-MM-DD` 只用那天以前的资料，
`--force-choice` 要求必选，`--no-judge` 防泄漏只看字面相似；`score` 的 `--include-leaked`
把可能泄漏的题也算进去；`--instrument` 换成自己的问卷 JSON（格式同
`src/twin/evals/instruments/survey_zh_v2.json`）。

**一个值得做的对比**：同一个分身，默认（允许说不知道）和 `--force-choice` 各答一次。
论文发现分身的准确率一部分来自"推断"资料里没写的答案；两次的差就是"诚实弃权"的代价，
作答率和"只算作答题的准确率"则是它换来的可靠性。

## 报告里的数字

| 指标 | 含义 |
| --- | --- |
| 准确率（弃权算错） | 分身的选择和你一样的题数 ÷ 你答了的题数；带按题 bootstrap 的 95% 区间 |
| 准确率（只算作答的题） | 分身没说不知道的题里，选对的比例 |
| 作答率 | 分身给出选择的比例 |
| 随机猜的准确率 | 每题 1/选项数的平均，用来判断分身是不是比瞎猜强 |
| 量表题平均偏差 | 五级量表题差了几档，换算到 0–1 |
| 理由像不像你 | 你给分身理由打的分（1–5） |
| 分身多次作答一致率 | 同一题几次作答选同一个答案的比例，衡量分身自己稳不稳 |
| 性格特质分数 | 每个特质 4 题的平均（反向题按 6 − 分数），你和分身各一组；偏差和相关 |
| 你两次作答的一致率 | 天花板：你自己隔一段时间能复现自己多少 |
| 归一化准确率 / 相关 | 同一批题上，分身 ÷ 你自己的一致率（相关同理） |

## 注意

- **答卷不要导入成记忆。** 否则之后的分身等于提前看了标准答案；防泄漏检查能发现一部分，但不能代替这条。
- **一个人、62 道题，区间会很宽。** 性格相关只有五个点，只看方向；结论要靠多位志愿者。
- 问卷只测"你说自己会怎么做"（自述）。"你实际怎么做"要用时间留出的行为评测，另行设计。

## 题目来源

- **性格 20 题**：Mini-IPIP（Donnellan 等，2006），出自公共领域的 IPIP 题库，商用不受限。
  中文是我们自己翻译的，**还没有经过效度验证**；正式研究时应换成已发表并验证过的中文版本，
  或先做试测。计分方向按原量表。
- **其余 42 题**：原创，按分身的人格细项出题，每题标了对应的细项（`facet`）。
  d1、d2 改编自风险偏好、时间偏好的常见设计；论文发现经济博弈信号很弱，v2 去掉了两道博弈题，
  换成两道相处方式的题。
- 精读笔记见 [paper/PARK_NOTES.md](paper/PARK_NOTES.md)。
